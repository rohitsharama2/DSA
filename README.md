## Learning philosophy

Understand the problem -> visualize state -> brute force -> find the bottleneck -> identify the pattern -> optimize -> dry run -> code -> complexity -> production connection.

## Target areas

- DSA: arrays, strings, linked lists, stacks/queues, hashing, trees, heaps, graphs, recursion/backtracking, dynamic programming
- CS / engineering: complexity, debugging, clean coding, distributed systems, system design
- AI: transformers, embeddings, RAG, agents, MCP, evaluation, AI system design

## Preferred language

Examples and solutions should use **Node.js + TypeScript** by default.
