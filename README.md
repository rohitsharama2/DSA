# DSA - Interview Preparation Handbook

A structured DSA, Computer Science, System Design, and AI interview-preparation repository centered on **Node.js + TypeScript**.

## Start here

- [Concepts and worked solutions](handbook/DSA-CS-AI-Concepts-and-Solutions.md) - detailed explanations, diagrams, TypeScript solutions, practice exercises, and video lessons
- `handbook/MAANG-DSA-AI-Interview-Handbook.pdf` - formatted study handbook
- `handbook/MAANG-DSA-AI-Interview-Handbook.md` - editable source
- `examples/README.md` - suggested structure for future solved problems

## Learning philosophy

Understand the problem -> visualize state -> brute force -> find the bottleneck -> identify the pattern -> optimize -> dry run -> code -> complexity -> production connection.

## Target areas

- DSA: arrays, strings, linked lists, stacks/queues, hashing, trees, heaps, graphs, recursion/backtracking, dynamic programming
- CS / engineering: complexity, debugging, clean coding, distributed systems, system design
- AI: transformers, embeddings, RAG, agents, MCP, evaluation, AI system design

## Preferred language

Examples and solutions should use **Node.js + TypeScript** by default.
