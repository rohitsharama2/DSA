# Phase 7 — Full rehearsal and final revision

**Reference:** [Concepts and worked solutions](../handbook/DSA-CS-AI-Concepts-and-Solutions.md). Section numbers below refer to this guide.

**Time:** Weeks 11–12.

Run two mock loops on separate days, adapted to the recruiter-confirmed format. A suggested practice loop is one coding problem, a practical/review exercise if relevant, one system design, and a values/project conversation. Spread sessions out if a full day is impractical.

Use this **self-assessment rubric**, not an Airbnb hiring rubric:

| Score | Meaning |
| --- | --- |
| 0 | Could not complete or explain the task |
| 1 | Needed major hints or left important correctness gaps |
| 2 | Independently completed the core task and explained decisions |
| 3 | Also handled follow-ups, trade-offs, and failure cases clearly |

Score problem framing, correctness, communication, testing, design reasoning, and behavioral specificity separately. Revise any area below 2 before adding more topics.

### Final readiness checklist

- [ ] Two recent coding mocks completed independently with tests and complexity analysis.
- [ ] One booking design explained through concurrent requests and partial failures.
- [ ] Practical/review preparation matches the confirmed interview format.
- [ ] Eight story notes and two project deep dives prepared from real experience.
- [ ] Role motivation and questions for interviewers prepared.
- [ ] Editor, language support, interview setup, and tool rules confirmed.
- [ ] Error log reviewed; recurring mistakes retried from scratch.

During the final 48 hours, revise familiar patterns, stories, and design trade-offs. Keep practice light enough to arrive rested.
