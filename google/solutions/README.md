- [General JavaScript implementations](general-coding.mjs): 28 problem solutions, plus DSU; heap imported from the Android track.
- [Android Studio JavaScript implementations](../android-studio-tech-lead/coding-solutions.mjs): all 16 target problems, plus the shared heap.
- The original TypeScript implementations are executed directly from Markdown by the existing example checker.

To run every Google solution check and validate links/coverage/code synchronization, from the repository root:

```sh
node google/solutions/check-all.mjs
```

For one example in a local Node session:

```js
import { subarraySum } from './google/solutions/general-coding.mjs';
console.log(subarraySum([1, -1, 0], 0)); // 3
```

Use Node's module mode for imports (for example `node --input-type=module` for stdin). Start with the question and attempt it before opening the answer; then trace the code and solve a changed requirement without notes.
