## Evidence rules

- No LeetCode Premium frequency dataset was accessed. The problem bank is a set of practice analogues, not a list of verified Stripe questions.
- S1/S2 offer clearer practical-round evidence than internship posts. Intern/new-grad reports were not used to establish senior expectations.
- Do not import one candidate's claimed completion cutoff as a company-wide pass rule.
- The JSON replay exercise defines its own equality and failure contract. It is not a clone of Stripe's real API or an exact interview statement.
- We did not fetch leaked debugging repositories or assume the reported library will be used again. Debugging drills are original.
- Confirm the current recruiter packet, including any AI-assisted format. An account describing permitted AI in one assessment does not authorize it elsewhere.

**Recruiter checklist:** exact level/team, coding vs. integration round names, debugging language, IDE setup, HTTP/file access, library/documentation availability, and design scope.
